# Changelog

## v0.1.0 — 2026-04-25

Initial release.

- Hostaway API client with OAuth client-credentials auth and in-memory token caching
- `list_listings` — list properties on the connected account
- `list_reservations` — list reservations with optional arrival-date and status filters
- `get_reservation` — full detail for a single reservation
- README with Claude Desktop config and usage examples
